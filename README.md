# Classify-Leaves-d2l-kaggle

基于微调resnet的叶子图片分类实验，这是沐神课程中的第二次竞赛，kaggle地址：[Classify Leaves | Kaggle](https://www.kaggle.com/competitions/classify-leaves)

## 主要工作

1. 使用resnet50的预训练模型进行微调。
   
   1. 只修改最后的全连接层，将Global_pooling后的通道数（2048）映射到类别数（176）
   
   2. 使用Kaiming Normal初始化这个全连接层；其他层仍然保持预训练参数
   
   3. 对这个全连接层使用1倍学习率，其他层使用0.1倍学习率

2. 对训练图片做数据增强。
   
   - 包括水平翻转、垂直翻转、随机裁剪、旋转、随机明亮度对比度

3. 使用Cosine退火学习率。
   
   - 总迭代次数为周期数，即每个周期迭代一次；设置最低学习率为1e-6

4. 使用多个随机初始化的模型做模型集成。
   
   1. 初始化多个模型，并分别进行训练
   
   2. 对于一个样本，将每个模型的预测输出做softmax，然后将不同模型的softmax结果做平均
   
   3. 对平均的softmax结果做argmax，得到最终预测结果

5. 选择超参数。
   
   - 批量大小为64，学习率为1e-3，训练周期数为150，权重衰减为1e-5
     
     1. 因为Cosine学习率在训练后期会降到很低，所以周期数较少时可能并不会真正收敛
     
     2. 将批量大小从256降低到64时精度更高了，可能是因为更小的批量带来的更多的随机噪声，增加了泛化能力；并且小批量可以带来更多的更新次数

## 其他工作

1. 定义数据集类
   
   1. 因为该数据集将图片地址和类别标签放在文件train.csv中，没法使用PyTorch的ImageFolder类（该类要求以类名命名文件夹，并将每类的图片放在对应文件夹下）
   
   2. 所以自定义一个数据集类，根据索引返回某个图片的内容和类别。
   
   3. 在该类的初始化中将字符串标签映射为整数标签，并根据参数区分训练集和验证集

2. 定义可视化类
   
   - 功能类似于d2l的Animator类，区别是可以画一行两列的子图，分别显示损失和准确率的变化情况

3. 使用数据并行进行训练
   
   - 将小批量划分到各个GPU中并行训练，提升训练速度
